# Topics

<sub>Verified against Claude Code v2.1.285 (stable) on 2026-10-05</sub>

Каждая страница темы перечисляет относящиеся к ней уроки по уровням сложности, факультативы, справочные разделы и официальную документацию. Страницы тем служат навигационными указателями и каталогизируют материалы. <details style="display:inline"><summary><code>[en]</code></summary>Each topic page lists its lessons in level order, its Electives, its reference page and the official docs. Topic pages link; they don't teach.</details>

- [Memory and context](memory-and-context.md): что Claude Code знает в начале сессии и чем заполняется его контекст в процессе работы.
- [Permissions and safety](permissions-and-safety.md): что Claude Code разрешено выполнять без подтверждения и как защитить критические файлы от нежелательного доступа.
- [Skills](skills.md): готовые пакеты инструкций, вызываемые по имени или подгружаемые автоматически при соответствии запросу.
- [Hooks](hooks.md): команды, запускаемые в фиксированные моменты сессии для строгого соблюдения правил без необходимости полагаться на память модели.
- [Subagents and parallel work](subagents-and-parallel-work.md): распределение задач по отдельным контекстам и сессиям: субагенты, worktrees, динамические воркфлоу и команды агентов.
- [MCP](mcp.md): подключение внешних инструментов и источников данных к Claude Code через протокол Model Context Protocol.
- [Plugins](plugins.md): наборы навыков, агентов, хуков и MCP-серверов, устанавливаемые из каталогов одним пакетом.
- [Automation](automation.md): автономный запуск Claude Code без прямого участия человека: скрипты, CI/CD и планировщики задач.
- [Models, effort and cost](models-effort-and-cost.md): выбор подходящей модели и уровня мыслительных усилий под задачу, а также контроль расходов токенов.
